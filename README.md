# OIBSIP Internship Projects

## Task 1 - Online Examination Application

### GitHub Repository

https://github.com/Prithik-Aswin-S/Prithik_Aswin_Task01

### Description

A web-based online examination platform that allows users to log in, update profiles, attempt MCQ-based examinations, and automatically submit tests when the timer expires.

### Features

* User Authentication
* Profile Management
* Password Update
* MCQ Examination
* Timer and Auto Submission
* Session Management
* Logout Functionality
